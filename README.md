# AlgoGenie Release

Cette branche contient uniquement les releases d'AlgoGenie.

## Releases disponibles

Voir les releases dans l'onglet Releases de ce repository.

## Installation

### Linux (Debian/Ubuntu)
```bash
sudo dpkg -i algogenie-*-linux-amd64.deb
```

### Windows
Double-cliquez sur le fichier .msi et suivez l'assistant d'installation.
